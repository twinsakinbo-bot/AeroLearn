## Sample JAMB Mathematics Questions with Solutions

### Question 1: Indices
**If 2^(x+1) = 32, find the value of x**

A. 3  
B. 4  
C. 5  
D. 6

**Answer: B (4)**

**Solution:**
```
2^(x+1) = 32
2^(x+1) = 2^5
Therefore: x + 1 = 5
x = 4
```

### Question 2: Quadratic Equations
**Solve: x² - 5x + 6 = 0**

A. x = 2 or 3  
B. x = -2 or -3  
C. x = 1 or 6  
D. x = -1 or -6

**Answer: A (x = 2 or 3)**

**Solution:**
```
Factorize: (x - 2)(x - 3) = 0
x - 2 = 0  or  x - 3 = 0
x = 2  or  x = 3
```
